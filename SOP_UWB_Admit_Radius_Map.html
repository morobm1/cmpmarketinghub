Property: UW Bothell Residential Village  |  System: Marketing Hub – Custom Tools

Section 1 – Purpose

The UW Bothell Admit Radius Map is an interactive admissions mapping dashboard that visualizes where admitted students and applicants are located relative to the UW Bothell campus. It helps leasing and marketing teams understand the geographic distribution of prospective residents, identify high-density markets, and make data-driven decisions for outreach campaigns and direct mail.

The tool categorizes students into distance bands from campus, provides filterable data views, and supports exporting professional reports and vendor-ready mailing lists.

Section 2 – When to Use This Process

Use this tool when you need to:

  • Visualize where admitted students live – See a map with color-coded pins by distance from campus
  • Analyze admissions data geographically – Understand which regions, cities, and states your prospective residents are coming from
  • Prepare direct mail campaigns – Export filtered, vendor-ready mailing lists based on distance, status, or housing interest
  • Generate executive reports – Create polished map reports (PNG or PDF) for presentations and stakeholder meetings
  • Track weekly admit list changes – Upload updated Excel files to see new admits and shifts in geographic distribution
  • Filter by specific criteria – Focus on admits who are interested in housing, specific application types, or within certain distance ranges

Tool Overview – Layout & Interface

The tool has three main areas:

Area Description
Left Rail (Sidebar) Contains KPI summary cards, filters (Status, Application Type, Housing Interest, Distance Band), search, legend, breakdown charts, and export tools
Map Area (Center) Interactive Leaflet.js map showing color-coded markers for each student, clustered for performance. Radius circles show 10, 50, and 100 mile boundaries from campus
Data Table (Bottom) Toggleable table showing filtered student records. Sortable columns, exportable to CSV. No personal names shown for privacy

Distance Bands

Students are categorized by straight-line distance from the UW Bothell campus (17927 113th Ave NE, Bothell, WA 98011):

Band Range Color Description
● Local 0–10 miles Green Local / campus area students
● Regional 10–50 miles Orange Greater Seattle / Puget Sound region
● Extended 50–100 miles Red Extended Washington state
● Out-of-State 100+ miles Purple Out-of-state and international

KPI Summary Cards

The top of the left rail shows live summary counts that update as you apply filters:

  • Total Records – Total number of students matching current filters
  • 0–10 mi – Count in the local band (green)
  • 10–50 mi – Count in the regional band (orange)
  • 50–100 mi – Count in the extended band (red)
  • 100+ mi – Count in the out-of-state band (purple)

Section 3 – Step-by-Step Instructions

Accessing the Tool

1 Navigate to Custom Tools

Log into the Marketing Hub and click Custom Tools in the navigation sidebar.

2 Add the Tool (First Time Only)

If the tool is not already in your toolbox:

  • Click "+ Add Tool"
  • Find "UW Bothell - Admit Radius Map" in the library
  • Click to add it to your toolbox

3 Open the Tool

Click the "UW Bothell - Admit Radius Map" card. It opens in a new tab at RV/index.html.

Using the Map

4 View the Map

When the tool loads, it displays all student records as color-coded markers on the map. Markers are clustered when zoomed out for performance. Click a cluster to zoom in, or click an individual marker to see details.

5 Read Student Popups

Clicking a marker shows a popup with:

  • Student status (e.g., Confirmed, Admitted)
  • City, State, and Zip Code
  • Application type
  • Housing interest
  • Distance from campus in miles

Note: No personal names or email addresses are displayed to protect privacy.

6 Use the Radius Circles

The map displays semi-transparent radius circles at 10 miles, 50 miles, and 100 miles from campus. These help you visually assess which distance band students fall into.

Filtering Data

7 Filter by Status

Use the Status dropdown in the left rail to filter by student status (e.g., Confirmed, Admitted, Applied, etc.). The map and KPIs update in real time.

8 Filter by Application Type

Use the Application Type multi-select dropdown to filter by application type (e.g., Freshman, Transfer). You can select multiple types.

9 Filter by Housing Interest

Use the Housing Interest dropdown to show only students who indicated interest in campus housing.

10 Filter by Distance Band

Click any legend item (color dot + label) in the Distance Bands section to toggle that band on/off. This lets you focus on specific distance ranges.

11 Search by City or Zip

Use the search box in the left rail to search for specific cities, states, or zip codes. The map will filter to show matching records.

Using the Data Table

12 Open the Data Table

Click the toggle bar at the bottom of the map area (labeled "Show Data Table" or similar) to expand the data table panel.

13 Sort and Review Data

Click any column header to sort the data by that column. The table shows all filtered records with columns for City, State, Zip, Status, Application Type, Housing Interest, Distance, and Band.

14 Export Table Data

Click the export button in the table header to download the currently filtered data as a CSV file.

Executive Map Report Export

15 Open the Report Builder

In the Export Tools section of the left rail, click "Executive Map Report".

16 Configure the Report

  • Title – Enter a custom report title or use a preset quick-select button
  • Subtitle – Optional subtitle for additional context
  • Format – Choose PNG (high resolution image) or PDF
  • Map View – Select auto-fit (shows all filtered records), current zoom, or full region
  • Filter Summary – Toggle whether to include the current filter settings in the report

17 Generate and Download

Click Generate Report. The system captures the current map view and generates a polished report with:

  • Header with title and date
  • KPI summary bar
  • Rendered map image
  • Distance band legend
  • Band breakdown percentages
  • Methodology footer

Privacy Note

No personal names or sensitive details are included in the executive report export. It only contains aggregated location data.

Direct Mail Export

18 Open the Direct Mail Builder

In the Export Tools section, click "Direct Mail Export". This opens a 3-step workflow.

19 Step 1 – Define Audience

Set your filters to define the mailing audience:

  • Filter by state, distance band, status, application type, housing interest, city, or zip code
  • Or use quick presets: Washington Only, Out of State, Within 50 Miles, Housing Interested Admits, Current App Filters

20 Step 2 – Preview & Validate

Review the audience before exporting:

  • Audience count – Total records that will be included
  • Address completeness warnings – Flags records with missing address data
  • State abbreviation checks – Validates state formats
  • Zip format validation – Checks zip code formatting
  • Preview table – See a sample of the output data

21 Step 3 – Export

Choose your export format and options:

  • Format – CSV or Excel (.xlsx)
  • PO Box exclusion – Option to exclude PO Box addresses
  • Address deduplication – Remove duplicate addresses
  • Capitalization normalization – Standardize name/address casing
  • Name inclusion – Names are excluded by default for privacy; toggle on if needed

The Excel export includes two sheets: Mailing List (vendor-ready rows with frozen headers) and Export Summary (segment metadata, filter details, band breakdown).

Refreshing the Dataset

22 Obtain Updated Excel File

Get the latest admit list Excel file from the university (e.g., ALL Admits for Autumn 2026_as of 3_13_2026.xlsx).

23 Pre-process the Data (Admin / Developer)

The data must be geocoded before use. An administrator runs:

cd RV
node geocode.js "New_File_Name.xlsx"
  • The script reads the Excel file and geocodes student addresses
  • Primary method: US zip code centroid lookup (instant, no API calls)
  • Fallback: OpenStreetMap Nominatim API for international/unknown locations
  • Results are cached in geocode-cache.json — subsequent runs use cached results for known locations
  • Output is saved to data.json

24 Refresh the Browser

After the data is preprocessed, refresh the browser to see the updated map with new data.

Section 4 – Expected Result

Expected Outcome

  • An interactive map displaying all admitted students as color-coded markers by distance band
  • Real-time KPI cards updating as filters are applied, showing counts per distance band
  • Filterable views by status, application type, housing interest, distance band, and search
  • Sortable data table with all filtered records for detailed review
  • Polished executive reports (PNG or PDF) ready for presentations
  • Vendor-ready mailing lists (CSV or Excel) for direct mail campaigns with address validation

Section 5 – Best Practices

Recommendations

  • Update data weekly – Re-run the geocoding script each time you receive an updated admit list to keep the map current
  • Use the Housing Interest filter – Focus on students who have expressed interest in campus housing for the most relevant outreach targets
  • Check the data quality indicator – The left rail shows a warning if records have missing/invalid addresses that couldn't be geocoded
  • Use distance band filters for targeted campaigns – Filter to 100+ miles for out-of-state mailing campaigns, or 0–10 miles for local event invitations
  • Use quick presets for Direct Mail – The preset buttons (Washington Only, Out of State, etc.) save time and reduce errors
  • Always preview before exporting mailing lists – Check the address completeness and validation warnings in Step 2 before generating the final file
  • Exclude names by default in exports – For privacy, keep name inclusion toggled off unless specifically required by the mail vendor
  • Use Executive Map Reports for stakeholder presentations – The auto-generated report includes all the KPIs, legend, and methodology without any PII
  • Zoom into specific areas on the map – Click clusters to drill down into high-density areas before generating a report for that region
  • Export the data table for custom analysis – Download the CSV from the data table for further analysis in Excel or Google Sheets

Data Privacy & Security

Important Privacy Information

  • No personal names or emails are displayed in the map interface or popups
  • Only aggregated location data (city, state, zip) is shown on the map
  • The data.json file strips all PII from the source Excel file
  • Executive reports contain no PII – Only aggregated statistics and map views
  • Direct mail exports exclude names by default – Names can be opted in if explicitly needed
  • Authentication required – Users must be logged into the Marketing Hub to access the tool

Technical Reference

Geocoding & Distance Calculation

Aspect Details
Origin Point 17927 113th Ave NE, Bothell, WA 98011 (lat: 47.7596, lng: -122.1892)
Distance Method Haversine formula (straight-line / great-circle distance)
Primary Geocoding US zip code centroid lookup via zipcodes npm package (instant)
Fallback Geocoding OpenStreetMap Nominatim API (rate-limited 1 req/sec)
Fallback Chain Full address → City + State → Zip code alone → State alone
Caching geocode-cache.json (server) + localStorage (browser)
Deduplication Records with identical Status + App Type + Street + City + State + Zip are flagged

Key Fields from Excel

The tool reads and uses these columns from the source Excel file:

  • Status – Student admission status
  • Application Type – Type of application (Freshman, Transfer, etc.)
  • Street 1, Street 2 – Address lines
  • City, State, ZipCode – Location data
  • Interested in Campus Housing? – Housing interest flag

Troubleshooting

Issue Solution
Map shows no markers Ensure data.json exists in the RV directory. Run node geocode.js if needed. Check that filters aren't excluding all records.
Some students missing from map Check the data quality warning in the sidebar. Students with missing/invalid addresses that couldn't be geocoded won't appear on the map but are still counted in totals.
Tool won't load Ensure you're logged into the Marketing Hub. Check browser console for errors. Try refreshing the page.
Executive report is blank Ensure map tiles have fully loaded before generating. Wait a few seconds after the map renders.
Direct mail export has missing addresses Check the validation warnings in Step 2 of the export builder. Some records may have incomplete address data in the source file.
Distance seems wrong Distance is calculated as straight-line (great-circle), not driving distance. Zip code centroids represent the geographic center of the zip code area, not the exact address.
