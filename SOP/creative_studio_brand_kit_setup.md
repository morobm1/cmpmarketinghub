# SOP: Setting Up a Brand Kit

**Department:** Marketing  
**System:** Creative Studio  
**Effective Date:** April 3, 2026  
**Category:** Company Wide  

---

## Purpose

This SOP explains how to create and manage **Brand Kits** in Creative Studio. A Brand Kit stores your property's colors, fonts, logos, images, links, snippets, and contact information so you can apply them to any email with one click. There are two ways to set one up: **manually** through the Brand Kit Manager, or by **uploading an Excel template** for bulk setup.

---

## When to Use This Process

- You're setting up Creative Studio for a property for the first time
- You need to add or update a property's branding (new logo, colors, etc.)
- You want to quickly apply consistent branding across all your emails
- You're onboarding a new property and need to bulk-load brand info

---

## Method 1: Manual Setup

### Step 1: Open the Brand Kit Manager

1. Open **Creative Studio** from the Marketing Hub
2. Click the **Brand** tab in the left sidebar
3. Click **"Manage Brand Kits"** (or the gear icon ⚙️) to open the Brand Kit Manager

---

### Step 2: Create a New Brand Kit

1. Click **"+ Create New Brand Kit"**
2. Enter a **name** for the brand kit (usually the property name — e.g., "Ivory University House")
3. You'll see sections for each type of brand asset

---

### Step 3: Fill In Brand Details

Work through each section:

#### Colors
- Add your **primary color** (main brand color)
- Add your **secondary color** (accent color)
- Add any additional brand colors
- Use hex codes (e.g., `#1A73E8`) or click the color picker

#### Fonts
- Set your **heading font** (used for titles and headlines)
- Set your **body font** (used for paragraph text)
- Choose from the available web-safe and Google Fonts options

#### Logos
- Upload your property's **logo** (PNG or SVG works best)
- Optionally add a **light version** for dark backgrounds
- Optionally add a **favicon** or icon version

#### Images
- Upload frequently used images (hero photos, amenity images, etc.)
- These will be available when editing emails to quickly insert property photos

#### Links
- Add commonly used links:
  - Property website URL
  - Application/apply link
  - Tour scheduling link
  - Social media URLs (Facebook, Instagram, TikTok, etc.)

#### Snippets
- Add reusable text blocks:
  - Property tagline
  - Standard disclaimer text
  - Lease special details
  - Amenity descriptions

#### Contact Info
- Property address
- Phone number
- Email address
- Office hours

---

### Step 4: Save the Brand Kit

1. Review all the information you've entered
2. Click **"Save Brand Kit"**
3. Your brand kit is now available in the Brand dropdown

> **Tip:** You can create multiple brand kits — one for each property you manage!

---

## Method 2: Excel Upload (Bulk Setup)

### Step 1: Download the Excel Template

1. Open the **Brand Kit Manager** (see Method 1, Step 1)
2. Look for the **"Upload from Excel"** or **"Bulk Import"** option
3. Click **"Download Template"** to get the Excel template file

---

### Step 2: Fill In the Excel Template

1. Open the downloaded Excel file
2. You'll see multiple sheets/tabs — one for each brand element:
   - **Colors** — Enter hex codes and color names
   - **Fonts** — Enter font family names
   - **Logos** — Enter image URLs or file paths
   - **Links** — Enter URLs with labels
   - **Snippets** — Enter reusable text blocks
   - **Contact Info** — Enter address, phone, email, etc.
3. Fill in each sheet with your property's information
4. Save the Excel file

> **Tip:** You can set up multiple properties in the same Excel file if the template supports it — check the column headers for a "Property" field.

---

### Step 3: Upload the Excel File

1. Back in the Brand Kit Manager, click **"Upload from Excel"**
2. Select your completed Excel file
3. The system will parse the data and show you a **preview of matches**
4. **Confirm the property matches** — make sure each row is mapped to the correct property/brand kit
5. Click **"Import"** or **"Confirm"** to create the brand kit(s)

---

### Step 4: Verify the Upload

1. After upload, open the brand kit in the Brand Kit Manager
2. Check that all colors, fonts, logos, and other details imported correctly
3. Make any corrections or additions manually if needed

---

## Editing an Existing Brand Kit

1. Open the **Brand Kit Manager**
2. Select the brand kit you want to edit from the dropdown or list
3. Make your changes to any section (colors, fonts, logos, etc.)
4. Click **"Save"** to update

> **Note:** Changes to a brand kit will NOT automatically update emails you've already created. You'll need to re-apply the brand kit to update existing drafts.

---

## Using "Rebrand My Draft"

This is the magic button! Once you have a brand kit set up:

1. Build or open an email in the canvas
2. Click the **Brand** tab in the left sidebar
3. Select your **Brand Kit** from the dropdown
4. Click **"Rebrand My Draft"**
5. Creative Studio will automatically update:
   - Colors (backgrounds, text, buttons)
   - Fonts (headings and body)
   - Logo (in header block)
   - And other brand elements
6. Review the changes and make any final tweaks

> **Tip:** "Rebrand My Draft" works great after using AI Generate or Guided Mode — build your content first, then brand it!

---

## Expected Results

After setting up a Brand Kit, you should:
- Have all your property's brand assets saved in one place
- Be able to apply branding to any email with one click
- Have consistent, professional-looking emails across all campaigns

---

## Best Practices

- **Set up brand kits early** — Do this before you start building emails. It'll save you tons of time.
- **Keep brand kits updated** — When logos or colors change, update the brand kit right away.
- **Use descriptive names** — Name your brand kit after the property so it's easy to find.
- **Include social links** — Having these in your brand kit makes it easy to add social icons to every email footer.
- **Test after rebranding** — Always review your email after clicking "Rebrand My Draft" to make sure everything looks right.
