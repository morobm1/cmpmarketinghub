Overview

What is Creative Studio? 🤔

Think of it as Canva for property marketing emails — drag, drop, and design without needing any technical skills!

  • 🧱 Drag-and-drop blocks — Stack content blocks like LEGO® bricks to build your email
  • 📋 Ready-made templates — Start from designs built for student housing
  • 🎨 Brand kits — Every property stays on-brand automatically
  • 📤 One-click export — Copy and paste right into Entrata Message Center
  • 🔗 Share links — Send a preview link to teammates for review

Templates

Start From a Template 📋

Don't reinvent the wheel! Templates give you a head start with pre-built layouts.

1. Browse

Click the Templates tab and browse by category — leasing, promos, events, renewals, and more.

2. Preview

Click Preview to see the full template before committing.

3. Customize

Click Use Template to load it, then swap in your property's text, images, and links!

💡 Pro tip: After customizing a template, save it as a new template so you can re-use it for future campaigns!
05 / 12
Builder

Building Your Email 🏗️

How It Works

  1. Drag a block from the left sidebar onto your canvas
  2. Click the block to select it
  3. Edit in the right-side properties panel
  4. Reorder by dragging blocks up/down on the canvas
  5. Repeat until your email is perfect!

Quick Actions

  • 📋 Duplicate — Copy a block
  • 🗑️ Delete — Remove a block
  • ↩️ Undo — Revert last change
  • ↪️ Redo — Re-apply a change

Media

Images & Background Removal 🖼️✨

Adding Images

  1. Click an image block (Hero, Logo, Gallery, etc.)
  2. Paste an image URL or browse the Image Library
  3. Drag from Brand Kit — images drop right onto the canvas!
💡 Use landscape images for hero banners. Always fill in alt text!

✨ Remove Background

Need a clean cutout? One click removes the background from any image!

  1. Select an image block
  2. Click ✨ Remove Background
  3. Wait a few seconds…
  4. Clean cutout! 🎉

Works best with clear subjects — people, objects, logos. First use takes a moment to load the engine.

Save & Export

Saving & Exporting 💾📤

Save Options

OptionWhen to Use
💾 Save DraftStill working on it
✅ Save CompleteReady to send
📋 Save As New CopyCreate a variation

Watch for the yellow "Unsaved" badge — save often!

Exporting for Entrata

  1. Click 📤 Export in the toolbar
  2. Choose Entrata Paste-In
  3. Click 📋 Copy to Clipboard
  4. Open Entrata → New Message → Source Editor
  5. Paste and you're done! 🎉
⚠️ Fix any export warnings (missing images, broken links, missing alt text) before pasting into Entrata!

Sharing for Review 🔗

Click Share in the toolbar to generate a read-only preview link. Paste it in Slack or Teams for teammate review!

Best Practices

Tips for Awesome Emails 🧠

📐 Structure

  • Keep emails scannable — short paragraphs, bullet points
  • One main CTA per email
  • Important stuff goes first
  • Always check mobile preview

✍️ Copy

  • Subject lines under 50 chars
  • Write like you talk to a friend
  • Use specific numbers ("Starting at $799")
  • Create urgency ("Only 3 spots left!")

🎨 Design

  • Less is more — 4–6 blocks per email
  • Stick to brand kit colors & fonts
  • Use high-quality property photos
  • White space is your friend
🪄 Power Move: Build "starter emails" for each type you send regularly (leasing, events, renewals) and save them as templates. Your team can crank out on-brand emails in under 10 minutes!
